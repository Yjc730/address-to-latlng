# address-to-latlng

# 📍 Batch Address to Latitude & Longitude Converter

A simple Python tool to convert multiple addresses into latitude and longitude using OpenStreetMap Nominatim API.

## ✨ Features
- Batch address input
- Automatic latitude / longitude conversion
- Export results to CSV
- Free & open-source (no API key required)
